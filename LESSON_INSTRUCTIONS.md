# Текст для инструкций проекта «Английский» в Claude

Скопируйте блок ниже в **Project instructions** (Инструкции проекта) проекта «Английский» на claude.ai.
Тогда в конце каждого урока Claude будет выдавать список слов в формате, который приложение
«Мои слова» понимает без правок.

---

```
В конце каждого урока (или когда я пишу «слова для приложения») выведи все новые
английские слова и выражения, которые мы прошли на уроке, ОДНИМ блоком кода в таком формате:

# Урок <номер или дата>: <тема>
english word or phrase | русский перевод | пример предложения на английском

Правила:
- одна строка = одно слово или выражение;
- глаголы — с частицей "to" (to give up), существительные — без артикля;
- если переводов несколько — через запятую в одном поле;
- пример — короткое естественное предложение из урока, если был;
- не добавляй ничего, кроме этого блока, внутри блока кода.
```

---

## Как перенести слова в приложение

1. В конце урока нажмите «Copy» на блоке со словами.
2. Откройте приложение **Мои слова** → вкладка **Добавить** → **Список из урока**.
3. Нажмите **«Вставить из буфера обмена»** → **«Добавить N слов»**.

Слова, которые уже есть в списке, не дублируются.

## Второй способ — через репозиторий

Слова можно добавлять в файл `words.json` в этом репозитории (например, попросить Claude Code:
«добавь слова из сегодняшнего урока в приложение» и вставить блок). После публикации приложение
само подтянет их при следующем запуске.
