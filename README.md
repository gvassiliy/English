# 📘 Мои слова — английские слова с уроков на iPhone

Приложение для изучения и повторения английских слов и выражений, пройденных на уроках.
Запускается с отдельной иконки на экране iPhone, работает без интернета.

## Возможности

- **Занятие по расписанию** — карточки с интервальным повторением (как Anki): слово приходит
  на повторение ровно тогда, когда вы начинаете его забывать. Кнопки «Снова / Трудно / Хорошо / Легко».
- **Тест** — выбрать правильный перевод из 4 вариантов (EN→RU и RU→EN).
- **Написание** — написать слово по-английски по переводу (опечатки прощаются).
- **На слух** — услышать слово и выбрать перевод.
- **Трудные слова** — отдельная тренировка слов, в которых чаще всего ошибаетесь.
- **Озвучка** английских слов голосом iPhone.
- **Список слов** по урокам, поиск, редактирование, статусы «новое / учу / выучено».
- **Добавление** слов вручную или целым списком из чата с уроком (кнопка «Вставить из буфера»).
- Серия дней подряд, статистика, резервная копия.

## Как установить на iPhone

1. Включите публикацию: на GitHub откройте репозиторий → **Settings → Pages** →
   в поле **Source** выберите **GitHub Actions**. Workflow `Публикация приложения` опубликует сайт
   по адресу вида `https://gvassiliy.github.io/English/`.
   > GitHub Pages для **приватного** репозитория доступен только на платном тарифе (GitHub Pro).
   > На бесплатном тарифе сделайте репозиторий публичным (Settings → General → Danger Zone →
   > Change visibility) — в нём только приложение и слова, ничего личного.
2. Откройте этот адрес на iPhone в **Safari**.
3. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
4. На экране появится иконка **«Мои слова»** — приложение открывается на весь экран, как обычное.

## Как добавлять слова с уроков

См. [LESSON_INSTRUCTIONS.md](LESSON_INSTRUCTIONS.md) — там текст, который нужно вставить
в инструкции проекта «Английский» в Claude, чтобы после каждого урока получать готовый список слов.

Два способа:
- **Быстрый:** скопировать блок слов из чата → в приложении «Добавить» → «Вставить из буфера».
- **Через репозиторий:** слова дописываются в `words.json` (например, через Claude Code) —
  приложение подтягивает их автоматически при запуске.

## Где хранятся данные

Прогресс и добавленные вручную слова хранятся на самом телефоне. Во вкладке **Ещё** можно
сохранить резервную копию в «Файлы» и восстановить её.
