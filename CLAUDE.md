# Мои слова — PWA для изучения английских слов

Статическое веб-приложение без сборки (index.html, app.js, styles.css, sw.js), ставится на iPhone
через Safari → «На экран „Домой“». Публикуется на GitHub Pages workflow'ом `.github/workflows/pages.yml`.

## Добавление слов с урока

Когда пользователь просит добавить слова из урока — дописывай их в `words.json` (массив `words`):

```json
{ "en": "to give up", "ru": "сдаваться", "ex": "Don't give up!", "lesson": "Урок 3: Phrasal verbs", "added": "2026-09-30" }
```

- `en` и `ru` обязательны; `ex`, `lesson`, `added` (YYYY-MM-DD) — желательно.
- Уникальность по `en` без учёта регистра — не дублируй существующие слова.
- Глаголы с "to", существительные без артикля.
- Не меняй порядок и не удаляй старые записи.

Приложение при запуске загружает `words.json` и добавляет новые слова, сохраняя прогресс
пользователя (он хранится в localStorage на телефоне).

При изменении файлов оболочки (app.js, styles.css, index.html) увеличь версию `CACHE` в `sw.js`.
